## 项目简介

Sentinel 是一个基于 Monad 链的交易安全工具。你在做 Swap 之前，它会自动检查多条交易路径，分析每一条链路的报价、流动性和历史安全性，然后告诉你：这条路能不能走、有没有坑、换哪条更安全。

同时，它还会用 AI 解释为什么这样判断，并且记录每笔安全交易，累积到里程碑自动解锁探员 NFT 勋章。

**一句话总结：** 每次交易前帮你扫一遍坑，安全的放心走，有问题的替你拦下来。

## 🎯 测试任务

### 步骤 1：打开页面，连接钱包
用 MetaMask 连接 Monad 测试链，看看能不能正常识别你的地址。

### 步骤 2：发起一笔 Swap
输入 100 USDT → USDC，看看不同链路的评分和 AI 分析有没有显示出来。

### 步骤 3：对比安全/不安全执行
分别用「安全保护」和「直接执行」走一遍，观察到账结果的差别。

### 步骤 4：看看 Dashboard
浏览仪表盘页面，看看评分、告警时间线和你的成就勋章。
