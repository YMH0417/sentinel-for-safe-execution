# 用户调研（User Research）

> 负责人：王敏桢（@minzhenw490-pixel）· 2026.07
> 项目：Sentinel — AI × Web3 交易安全助手（Monad 黑客松二等奖）

## 这份调研解决什么问题

Sentinel 要在发交易之前帮用户判断「这条路径安不安全」，关键在于搞清楚两件事：

1. DeFi 用户真实怕的是什么？（恶意授权、钓鱼、复杂合约提示看不懂）
2. 用户愿意把多少风险判断交给 AI？什么情况下才信任它的解释？

## 调研方法

| 项目 | 内容 |

## 报告怎么影响产品

- **风险提示要用白话**：用户看不懂合约提示，需要 AI 用日常语言解释「这笔交易在干什么、有什么风险」；
- **AI 只做建议，不做决定**：用户要保留最终确认权，AI 不能代替签名；
- **信任来自可核验**：每条风险判断要能说清依据（哪条路径、哪个权限、哪个池子）。
