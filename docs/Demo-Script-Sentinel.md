# 🎬 Demo Script — Sentinel for Safe Execution

> **时长：** 约 2 分钟
> **形式：** 对照演示（无保护 vs 有 Agent）
> **面向：** Hackathon 评委 / 观众
> **定位：** 给 DeFi 用户用的「交易安全助手」
> **Slogan：** Don't trade naked. 🛡️

---

## 🎬 场景设定

```
用户：小明（普通 DeFi 用户）
目标：把 100 USDT 换成 MON
状态：完全不知道哪个池子是安全的
```

---

## 第一轮：没有 Safety Agent ❌

> **约 40 秒**

**🎙️ 讲述：**
> 「这是小明。他想把手上的 100 USDT 换成 MON，于是他打开了一个 DEX，选了池子，点了 swap。」

**🖥️ 屏幕操作：**
- 打开 Demo 页面
- 输入 100 USDT → MON
- 系统返回一个 route 报价（正常显示）
- 点击 Swap → 交易执行

**🎙️ 讲述：**
> 「交易完成了……但等等，他选到了一个**异常流动性池**。到手只有 97.8 MON，比市场价少了 2.2%。还白花了 Gas。」

**🖥️ 屏幕显示：**
- 交易成功，但到账金额明显比预期少
- 弹出一个事后提示：「该池报价偏离市场均值 2.3%」

**🎙️ 讲述：**
> 「问题是：**发交易之前，没人告诉他这池子有问题。**」

---

## 第二轮：有 Safety Agent 🔒

> **约 60 秒**

**🎙️ 讲述：**
> 「现在，同样的 swap，小明打开了 Sentinel。」

**🖥️ 屏幕操作：**
- 勾选 / 打开「Safety Agent 保护」
- 同样输入 100 USDT → MON
- 系统获取候选 route（显示 2 条）

**🎙️ 讲述：**
> 「Agent 拿到了两条候选路径，然后开始做安全检查——」

**🖥️ 屏幕逐步展示 Agent 检查过程：**
```
✅ Route A 检查通过 → ALLOW
❌ Route B 报价偏离 2.3% → REJECT
   ↓
   显示拒绝原因：「报价偏离阈值过大，超出安全范围」
```

**🎙️ 讲述：**
> 「Route A 报价正常，放行。Route B——就是刚才小明走的那条——Agent 检测到报价偏离了 2.3%，直接拦截了。」

**🖥️ 屏幕显示：**
- Route A 执行成功，100 USDT → 100.2 MON
- 旁边对比显示：如果没有 Agent，走 Route B 只有 97.8 MON

**🎙️ 讲述：**
> 「同样的金额，同样的目标。有 Agent 保护，到手 100.2 MON；没有 Agent 保护，只有 97.8 MON。**差了 2.4%——不是因为价格波动，只是因为选错了池子。**」

---

## 第三轮：NFT 里程碑奖励 🏆

> **约 30 秒**

**🎙️ 讲述：**
> 「每次 Agent 帮你成功完成一笔安全交易，你的账户就会累计一次『安全执行次数』。」

**🖥️ 屏幕切换到用户 Profile 页面：**
```
🏅 安全探员勋章

  当前安全交易：12 / 10
  ┌─────────────────────────────┐
  │ 🥉 铜牌探员   10 笔安全交易  │ ● 已解锁 ✅
  │ 🥈 银牌探员   50 笔安全交易  │ ○ 进行中 (12/50)
  │ 🥇 金牌探员  100 笔安全交易  │ ○ 锁定
  │ 💎 钻石探员  500 笔安全交易  │ ○ 锁定
  └─────────────────────────────┘
```

**🎙️ 讲述：**
> 「到达里程碑，自动 mint 对应等级的探员 NFT——这是你『聪明交易者』身份的链上证明。」
>
> 「你用得越久，Agent 保护你越多，你的勋章墙就越闪亮。」

**🖥️ 点击已解锁的铜牌 NFT，展示详情：**
```
🥉 铜牌探员 NFT
安全交易次数达标：10 笔
持有者：0xABC...123
状态：已 mint 上链 ✅
```
