---

## 一、产品定位

**一句话：**
> 给 DeFi 用户用的「交易安全助手」，帮助用户在交易前判断哪条链、哪条路径更安全，避免踩坑。

**产品定位：**
> A transaction security layer for DeFi users that evaluates blockchain risks, route safety, and execution conditions before transactions.

## 二、核心用户流程（User Flow）

```
用户进入产品
     │
     ▼
┌──────────────────┐
│  连接钱包          │
└──────┬───────────┘
       ▼
┌──────────────────┐
│  输入交易参数      │  Token In / Token Out / Amount
│  (Swap 式输入)    │
└──────┬───────────┘
       ▼
┌──────────────────┐
│  获取报价 & 路径   │  GET /quote → 返回候选 Route 列表
└──────┬───────────┘
       ▼
┌──────────────────────────────┐
│  Safety Agent 风险评估         │  POST /evaluate
│  ├─ ALLOW   → 安全，可直接执行  │
│  ├─ REJECT  → 高风险，拦截     │
│  └─ FALLBACK → 自动切安全路径  │
└──────┬───────────────────────┘
       ▼
┌──────────────────┐
│  执行交易          │  POST /execute
│  + 事件时间线展示   │
└──────┬───────────┘
       ▼
┌──────────────────┐
│  NFT 成就记录      │  交易量累计 → 解锁勋章
└──────────────────┘
```

## 七、API 对接

## 八、NFT 成就系统说明

**定位：** 交易量里程碑奖励，不是链上身份绑定

| 等级 | 名称 | 解锁条件 |
|------|------|----------|
| 🥉 铜牌 | 铜牌探员 | 10 笔安全交易 |
| 🥈 银牌 | 银牌探员 | 50 笔安全交易 |
| 🥇 金牌 | 金牌探员 | 100 笔安全交易 |
| 💎 钻石 | 钻石探员 | 500 笔安全交易 |

**技术说明：**
- Demo 阶段链下记录（数据库存计数）
- 里程碑达标后触发 mint
- NFT 一旦发放不可修改
- 前端通过链上数据渲染勋章形象
- P2 优先级，核心闭环完成后开发
